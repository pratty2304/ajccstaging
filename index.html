Choose a site. Enter T, N, and M. Stagewise returns the AJCC stage group using the current protocol for that disease.

Stagewise is an educational TNM grouping tool. It does not reproduce copyrighted AJCC manual text, does not assign treatment, and cannot replace a registered AJCC protocol or specialist review. Lung and nasopharynx use AJCC Version 9 (effective 2025) and HPV-associated oropharynx uses Version 9 (effective 2026). All other sites use the AJCC 8th Edition, which remains current until a Version 9 protocol replaces it.
